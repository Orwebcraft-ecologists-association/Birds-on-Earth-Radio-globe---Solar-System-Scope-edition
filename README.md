# Birds on Earth Radio — 0.5 Solar Scope Edition

Open the [Google AI Studio project](https://ai.studio/apps/d43affde-e9a9-47c1-a50e-f9fb848ccb52) or the [hosted app](https://birds-on-earth-radio.ai.studio/).

## Run locally

Use Bun to install the dependencies recorded in the AI Studio export.

```sh
bun install --frozen-lockfile
bun run dev
```

See [Google Play setup](docs/GOOGLE_PLAY.md) for the Android wrapper and AAB build.
